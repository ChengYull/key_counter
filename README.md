# key_counter
统计键盘按键次数，按日统计  基于 PyQt6

## 功能特性
- 实时统计：自动记录每个按键的按压次数
- 热力图可视化：直观展示按键使用频率分布
- 便捷操作：
    - 窗口置顶功能（始终可见）
    - 界面滚轮缩放（调整热力图大小）
    - 数据自动保存
